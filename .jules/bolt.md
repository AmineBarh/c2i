## 2026-06-01 - Component Re-rendering on Typed Inputs\n**Learning:** The `Admin.jsx` dashboard calculates complex state derivations (filtering arrays and accumulating counts by category) sequentially on every render. Because the search input state updates frequently as the user types, these sequential O(N) array passes execute constantly, causing lag.\n**Action:** Use `useMemo` to wrap computationally expensive derivations that depend on list sizes. Also, when filtering arrays with string matching based on user input, hoist `.toLowerCase()` calls outside of `.filter()` loops to avoid repetitive allocations.
