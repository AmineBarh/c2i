## 2025-05-31 - Memoizing Derived Arrays and Objects inside Context/UI Changes
**Learning:** In the `Admin.jsx` and `TrainingDashboard.jsx` components, array `.filter()` calls were executing on every component re-render. Since these components handle UI state changes (like sidebar toggling or modal overlays) or high-frequency input (like `searchTerm`), the entire dataset was unnecessarily recomputed repeatedly. Additionally, `Admin.jsx` used sequential O(N) `.filter().length` passes to count project types instead of a single O(N) `reduce`.
**Action:** Always wrap computationally expensive list processing (filtering, mapping, reducing) inside `useMemo` in React components, especially if the component tracks unrelated high-frequency state updates. Ensure multiple O(N) passes are combined into a single pass where possible.
