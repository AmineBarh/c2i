## 2025-02-12 - Re-rendering limits in complex filtering operations
**Learning:** In React components that handle dynamic lists and user inputs (like checkboxes alongside search inputs), derived states such as `filteredTrainings` and aggregation `stats` can silently become major performance bottlenecks. Even with small arrays, recreating `Set` instances and executing $O(N)$ text filters during every render cycle (e.g. when checking a single box) consumes main thread time.
**Action:** When finding sequential `.map()` and `new Set()` operations used to count unique categories from state, merge them into a single $O(N)$ `forEach` pass and wrap the output in `useMemo`. Apply `useMemo` aggressively to filtering logic that depends on `O(N)` string matches, ensuring it runs only when the raw data or search query actually changes.
