## 2024-04-01 - Avoid Sequential .filter().length Operations in React UseMemo Hooks
**Learning:** In the `Admin.jsx` dashboard, the application calculated total metrics by running three consecutive O(N) `.filter().length` passes over the exact same `projects` array (`iotProjects`, `webProjects`, `automationProjects`). When placed inside a functional component without memoization, these recalculate on every single state change (e.g., just toggling the sidebar), causing a minor but unnecessary performance penalty.
**Action:** When calculating counts for multiple distinct categories from a single array in React, combine the operations into a single O(N) `forEach` or `reduce` loop, and immediately wrap that loop inside a `useMemo` hook to compute it once and prevent recalculations during unrelated renders.
