## 2023-10-27 - Consolidated Multiple O(N) Passes and Memoized Component Computations
**Learning:** In components rendering lists alongside metadata (like categorized counts), filtering an array and subsequently generating counts via separate `.filter().length` passes executes multiple O(N) operations sequentially. In React, these operations fire on every render (e.g., when a user types in a search bar), exacerbating input latency and unnecessary CPU load.
**Action:** Always combine related array derivations (like building a filtered list and calculating categorical counts) into a single iteration using `.forEach()` or `.reduce()`, and wrap the computation in `useMemo` when working with prop-derived data. This pattern was applied to `Admin.jsx` and `TrainingDashboard.jsx` to optimize high-frequency rendering flows.
